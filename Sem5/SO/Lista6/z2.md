The block group descriptor table is an array of block group descriptor, used to define parameters of all the block groups. It provides the location of the inode bitmap and inode table, block bitmap, number of free blocks and inodes, and some other useful information. 


Cokolwiek w systemie plików ext2 jest podzielone na małe grupy sektorów nazywane blokami
Bloki są łączone w grupy, głównie dla wydajnosci
W niektórych grupach bloków zapisywany jest superblok (1 blok) oraz tablica deskryptorów (number_of_groups * 32 / block_size (bo kazdy wpis ma 32 bajty)), ze względu na wydajnosc
we wszystki znajduje sie:
- Bitmapa bloków - 1blok
- Bitmapa i-węzłów - 1blok
- Tablica i-węzłów - s_inodes_per_groub * s_inodes_size / block_size
- Bloki danych - reszta
